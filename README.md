# tg-ws-proxy-docker

Docker image for [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).

This repository contains an automated Docker build published to GitHub Container Registry:

```text
ghcr.io/q7nm/tg-ws-proxy
```

> **Note**
> This project does **not** modify the original application. It only provides a ready-to-use Docker image for easier deployment.

## Credits

All credit for the application itself belongs to the original project:

- https://github.com/Flowseal/tg-ws-proxy

If you're looking for documentation, configuration options, or information about how `tg-ws-proxy` works, please refer to the original repository.

## Pull image

```bash
docker pull ghcr.io/q7nm/tg-ws-proxy:latest
```
